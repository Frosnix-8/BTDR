# how to play?
1: download your version, Mac or windows. (sorry linux users)
2: extract the ZIP (location is irrelevant)
3: add to steam via "add a non-steam game"
4: play

## solutions for issues:
Q: spacewar opens when I launch!
A: add steam_appid.txt in the exe's directory, and just put "480" inside it.

Q: I get some weird error when I launch it!
A: if reloading the network fails, refer to question 1. make sure you added it to steam. It could work otherwise, but it means you don't need this answer.

Q: the game is laggy!
A: check if you are running lots of stuff in the background. This game shouldn't be very heavy, except if you have old computers.

Q: the game lags when I load in!
A: that's normal. the shader baker is off for reasons I cannot explain. The game computes them at runtime, which is laggy when you first load in.

Q: the game won't launch or it crashes!
A: check your platform version. if it's the right one and it still doesn't work, report the issue on this repo. if you have any error codes or reasons given, please include them.

## some basic controls
wasd: movement
left click: charge a throw. aim for the green! yellow is just fine as well: your throw will be stronger and deal more damage.
right click: aim a throw. you'll zoom in and have lower sensitivity for those snipes.
1-2-3-4: select an inventory slot. if it's not working, that slot is empty.
ctrl + reverse slash : toggle a blizzard. won't work if you're not a host. sorry!
clipboard cut: quit the game. (same as alt + f4)
minus : killbind.
ctrl : crouch
shift: sprint
